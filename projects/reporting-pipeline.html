Enterprise agentic analytics platform

At General Electric Credit Union I built the organization's first agentic analytics workflow. An agent drafts the SQL and the report, governed data keeps it accurate, and a person makes the final call.

Key result. Report turnaround went from 2 weeks to 48 hours, with 25+ reports delivered into daily production.

How it works

A data request arrives as a Jira ticket. An agent drafts the SQL and the report against governed data, an analyst reviews it, and it goes to production.

  1. Jira requestA stakeholder asks for data
  2. Agent draftSQL and report, using governed context
  3. Human reviewAn analyst checks and approves
  4. Production releaseA repeatable, documented workflow

It connects Claude to Snowflake, DataHub, Jira, GitHub and Figma through the Model Context Protocol (MCP) and Python.

What I built

  • The workflow itself. The credit union's first agentic analytics workflow, from ticket intake through production release.
  • Governed data context. Context in Snowflake and DataHub so agents can navigate the data and interpret metrics correctly.
  • Human-in-the-loop review. Every report is checked and approved by an analyst before it ships.
