A credit union's first agentic reporting pipeline

At General Electric Credit Union I built the organization's first agentic analytics workflow. A data request arrives as a Jira ticket. An agent drafts the SQL and the report against governed data, an analyst reviews it, and it goes to production.

It connects Claude to Snowflake, DataHub, Jira, GitHub and Figma through the Model Context Protocol (MCP) and Python.

Approach

How I work with AI agents

I direct AI coding agents to build these systems. I set the requirements, make the product decisions and decide what ships. A few rules show up in everything I build.

  • A person holds the authority

    Agents draft, advise and execute inside written rules. In the trading system the review board can question and escalate, but it can't trade, veto or change the rules.

  • Nothing sensitive leaves unchecked

    Before any text goes to an outside model, account numbers and order IDs are replaced with labels. A second check stops the send if anything was missed.

  • Missing data stays missing

    If a number isn't available, the screen says so. The desk display never fills a gap with an estimate or sample data.

  • Tests run without the real thing

    The test suites use fake files and fake clients, so they need no network, no API key and no real account data.
